# qaqh-tui v2.0.0-beta.2 发布说明（2026-10-04）

> 预发布。第二个 beta：工具卡渲染重构 + 会话状态修复 + markdown 渲染器拆模块与表格
> 折行。版本号沿用后端 `docs/plan-beta-release.md` §0 的 semver 预发布口径
> （`2.0.0-beta.2`），与 backend 仓 workspace 成员版本对齐。

## 1. 这个版本是什么

**渲染层收口：工具卡与 markdown 两块渲染器都从「够用」推到「可读」，会话状态的三类
幽灵态一并清掉。**

- 工具卡渲染重构（`322fa3d`）：删掉独立状态行，状态折进头部动词；正文用 `└ ` 连接符
  + 整体 dim；指标收敛成一枚 `+N −M` 徽标；折叠提示可点；终端正文只留 3 行预览。
- 会话状态修复（`322fa3d`）：幽灵 Running 的三条泄漏路径、子代理会话混进列表、会话
  列表 3s 抖动，都在状态机层面修掉而不是在渲染层打补丁。
- markdown 渲染器（`b0616ed`）：模块划分对齐 codex 的 `markdown_render.rs` +
  `markdown_render/`；表格列宽与折行机制取自 grok `xai-grok-markdown`。

## 2. 工具卡与会话状态（`322fa3d`）

### 2.1 工具卡

- 头部一句话说清「跑了什么、结果如何」：`Ran cargo test` / `Failed (code) Tool` /
  `Running`，不再有独立的 `状态: …` 行。
- 正文挂 `└ ` 连接符 + 整体 `text.muted`；无工具调用时间戳（回看时是噪音）。
- 指标一枚徽标：文件名后 `+2 −1`，时长仅在 ≥1s 出现，不再显示字节数。
- 折叠提示 `… +N 行（点击展开）`；终端侧预览 `DETAIL_PREVIEW_LINES = 3`。
- stderr 用颜色区分而不是独占一行；diff 保留行号 gutter；`@@` 段头改用
  `diff.gutter_fg`（此前误用 `semantic.command`）。
- 头部按显示宽度逐 span 截断，不再整体截断或折行。
- 连续查表族（read/grep/glob）同回合合并成一张卡：transcript 与 fullscreen 共用
  `lookup_group_len` / `render_lookup_group`；合并卡只有一个命中区且指向首个成员，
  点开即拆组、剩余成员继续合并。

### 2.2 会话状态

- 幽灵 Running（三条路径）：`running_turn_id` 只认最后一回合；快照重基线不得把终态
  回合退回 Running；`TurnFinished` / `TurnInterrupted` 单调封印 timeline，补上后端
  `TurnSealed` 被双限淘汰的缺口。三条各有回归测试，去掉任一修复即红。
- 子代理会话从侧栏与历史列表隐藏——按 roster 的 `parent_agent_id` 判定，不用会漏掉
  已完成子代理的 `subagent_session_ids`。
- 会话列表抖动：daemon 按 `updated_at` 排序 + 每条消息刷新 + 3s 全表替换 → 改为稳定
  排序，周期刷新只更新内容不重排，新会话插队首、删除的消失。

### 2.3 布局与用量

- 底部两行并成一行：预算分配装配，必需项（连接相位 + 活动）与时钟是地板，快捷键
  提示优先分配，常驻项吃剩余、不足时整块让位；诊断/提示条出现时提示让位。
- 子代理预览条：14 列 × 1 行、可点击、按 roster 的 Running 自动消失；窄于 32 列
  隐藏。
- 用量三元组回归（context % / tok·s⁻¹ / cache %）：各自数据齐备才渲染，流式中不显示
  tok/s，cache 用 `cache_usage_reported` 区分真实 0% 与未上报。

## 3. markdown 渲染器（`b0616ed`）

拆法对齐 codex：事件状态机留在 `markdown.rs`（1302 → 520 行），代码高亮 / 表格 /
行内折行 / 列表各自成子模块（`markdown/{code,list,table,text,tests}.rs`），调用方路径
不变。

表格机制取自 grok `format_table`：

- 列宽三层：`natural`（该列最宽单元格）→ `word_floor`（最长不可断单元）→
  `hard_floor`（最宽单个字符）。预算够就直接用 natural，不够逐层退让；选定地板后把
  剩余预算按各列「未满足的余量」比例分下去——取代原先 `avail / cols` 平分（宽度悬殊
  的表曾被拉成等宽：窄列灌空格、宽列反被 `…` 截断）。
- 单元格真正折行：断点优先空白，其次 `/ - , 、 :` 这类标点，中文按单字可断，只有单个
  超长 token 才降到字符级硬切；行高取本行各格折行数的最大值。
- `<br>` 在单元格内是换行。旧实现里 `handle_table_event` 只要 table 存在就无条件吞掉
  所有事件，`第一行<br>第二行` 会粘成一行。
- 列数被 `max_cols` 截断时补一行「表格省略 N 列」——原先整列静默丢弃。
- `format_cell` 只在 `display_width > width` 时截断：`==` 表示整格正好填满，4 宽列里
  的 `name` 曾被截成 `nam…`。
- 顺带开 `Options::ENABLE_GFM`（0.12 里它只解锁 blockquote tags）：`> [!NOTE]` /
  `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]` 渲染成带标签抬头的引用块，
  各类型用各自的语义色。

## 5. 已知限制（请一并发布）

- **本轮无真实模型 e2e**：端到端验证仍只到「握手 + session 协商」层，真实回合（模型
  调工具 → 回灌 → 渲染）未在本发版窗口重跑。
- **markdown 尚未上流式**：表格/代码块仍是整块渲染。codex 的 `markdown_stream` +
  `table_holdback`、grok 的 checkpoint 冻结都还没搬，流式期间表格可能先按半张表渲染
  再重排。
- **表格折行不走 grapheme cluster**：`widest_char_width` 用 `char` 近似（不引入
  `unicode-segmentation`），emoji ZWJ 序列按多字符计宽。方向只会让地板更保守。
- **两处待定取舍（记录在案）**：`stable_session_order` 目前只在首次加载 / 新会话时
  重排（「最近更新上浮」不再是常态）；子代理条目前只显示数量，单子代理时未显示昵称。
- **环境差异**：`HOME` 未设置时 `transcript::tests::tool_header_shortens_paths_but_body_keeps_them`
  会红（该测试依赖 HOME 做 `~` 缩短），本版未修。
- 依赖关系：`qaqh-client` / `qaqh-config-api` 为 `../qaqh-backend` 路径依赖，单独分发
  TUI 源码需连带后端仓（既有取舍）。

## 6. 运行与回滚

构建与运行同 v2.0.0-beta.1（`cargo build --bin qaqh-tui`，需要 `../qaqh-backend`
兄弟仓）。本版三个提交相互独立，可分别回退：`b0616ed`（markdown）、`322fa3d`
（工具卡 / 会话状态）、`9a4002e`（rustfmt，纯空白）。
