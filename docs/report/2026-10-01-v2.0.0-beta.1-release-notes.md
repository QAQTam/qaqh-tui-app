# qaqh-tui v2.0.0-beta.1 发布说明（2026-10-01）

> 预发布。首个 beta：协议权威化收口 + 独立白盒安全审计修复。版本号遵循后端
> `docs/plan-beta-release.md` §0 的 semver 预发布口径（`2.0.0-beta.1`）。

## 1. 这个版本是什么

**协议 Ringing v2 已是唯一权威路径，TUI 自身安全边界经白盒审计并修复。**

- 协议权威化（`75da060`）：删除状态机自维护镜像，握手/续租/流全部统一消费
  `qaqh-client`；协议代差由 open 协商守卫（426 不重试）。
- 独立白盒安全审计（`7b0efba`，`docs/audit/2026-10-01-TUI独立白盒安全审计报告.md`）
  产生 6 项发现，本版修掉 TUI 侧 4 项（见 §2）；F3（审批应答无内容绑定）移交
  后端审计，F6（OSC 52 剪贴板，用户触发、设计使然）记录在案。
- 仓库瘦身（`5499846`）：移除旧 CI、e2e 脚本套件与过期文档；门禁收敛为
  `cargo test` / `clippy -D warnings` / `fmt` / `doctor` 端到端自检。

## 2. 本版修掉的安全发现（审计编号）

1. **F1【中危】权限审批弹窗无滚动、溢出静默裁剪**——用户看到的 ≠ 批准的。
   正文可滚动（↑↓/j/k/PgUp/PgDn），超出视口不再被裁掉；footer 常驻
   「⚠ 还有 N 行未显示」警示；路径不再 `take(6)` 截断，第 7 条起滚动可达。
2. **F2【中危】pager 临时文件**——正文先剥离全部 ANSI/VT 转义再落盘
   （`less -R` 直通与 `cat` 回退都不再收到 OSC/CSI 序列）；临时文件改
   `O_CREAT|O_EXCL` 独占创建 + 持句柄写入，根除可预测路径 symlink 覆盖
   （CWE-377）。
3. **F4【低-中】`/export` 任意路径写**——显式路径覆盖已存在文件或含隐藏
   组件（`~/.bashrc`、`~/.ssh/*`）时先二次确认，确认层绑定发起会话。
4. **F5【低】Secret 编辑态明文回显**——API Key 输入过程整值掩码为 `*`，
   并隐藏硬件光标（光标偏移会泄漏输入长度）。

新增回归测试 7 项锁定上述行为。

## 4. 已知限制（请一并发布）

- **本轮无真实模型 e2e**：原 scripts/ e2e 套件已随瘦身移除，本周期端到端
  验证仅到「握手 + session 协商」层；真实回合（模型调工具→回灌→渲染）
  未在本发版窗口重跑。
- **审计遗留的动态验证项**：F1/F2 的端到端利用路径已从 TUI 侧根除，但真实
  终端（less 版本差异、Windows 终端对 OSC 的支持）下的复测仍建议按审计
  报告 §最终总结.4 的清单走一遍。
- **后端侧 beta 门禁未重跑**：后端仓 `plan-beta-release.md` §1.1（workspace
  全量）/ §1.2（smoke-g1）在该仓另行执行，本说明只覆盖 TUI。
- 依赖关系：`qaqh-client` / `qaqh-config-api` 为 `../qaqh-backend` 路径依赖，
  单独分发 TUI 源码需连带后端仓（既有取舍）。
- Windows 下 daemon 无沙箱强制（后端 `SandboxCapabilities` 如实上报）。

## 5. 运行

```bash
cargo build --bin qaqh-tui          # 需要 ../qaqh-backend 兄弟仓
./target/release/qaqh-tui           # daemon 未运行时自动拉起（QAQH_BACKEND_ROOT 或同目录）
./target/release/qaqh-tui doctor    # 自检：发现/pid 判活/open 握手
```

环境变量：`QAQH_DATA_DIR`、`QAQH_BACKEND_ROOT`、`QAQH_DEFAULT_CWD`、
`QAQH_THEME`（night/day/terminal/auto）、`QAQH_TUI_LOG`（诊断日志）。
