## 1. 现状差距（已核对代码）

| Spec 要求 | 当前实现 | 差距/风险 |
|---|---|---|
| 每帧单一 HitMap | `modal::hit_test`、`workspace_hit_test` 在事件到达时重跑布局；Agent 用 `FullscreenView::message_at` 查上次绘制留下的 spans | 绘制与命中仍是两条路径，无法证明“看到的就能点” |
| HitRegion 含 clip/z/enabled | 只有 `ModalHit` / `WorkspaceHit` 语义枚举；无 rect、clip、z、anchor | 遮挡、裁剪、disabled、同 z 冲突均不可验证 |
| 事件绑定 presented frame | 无 `FrameId`；`handle_message` 使用当前 App 状态和传入 route | resize、滚动、路由切换后可能用旧坐标解释新画面 |
| 批量消息路由正确 | `run_loop` 在批次开始前解析一次 `route`，同一 `route` 传给整批消息（`agent/mod.rs:203-229`） | 批次内键盘先切路由、后续鼠标仍走旧路由，直接违反 spec §3.3 |
| 统一指针状态机 | Modal 在 `App`、Workspace 在 `App`、Agent 在 `FullscreenView`，消息菜单又另存 hover/pressed | hover/pressed/capture 清理规则分散，容易漏 stale 状态 |
| 单一按钮模型 | `modal.rs`、`workspace.rs`、`fullscreen.rs` 各有一套 `ButtonVisual`/style | disabled、pressed、focused、无颜色降级会漂移 |
| 鼠标捕获唯一所有者 | 启动/退出全局开启关闭；pager 重初始化后再次开启，但未显式成对关闭 | 异常路径、pager、panic 的 enable/disable 配对缺证 |
| 滚动条可交互 | 只绘制 thumb，无 HitRegion、track click、drag capture | spec P2 未实现 |
| 故障探针 | 无 `QAQH_HIT_PROBE`，无探针反例测试 | 无法在 CI/PTY 中证伪 XY 错位 |
| 测试覆盖 | 有 Modal/Workspace 命中单测、hover 视觉、Modal PTY 点击；E2E 坐标仍手抄布局公式 | 缺四角/外扩/遮挡/stale/resize/capture/探针反例矩阵 |
| 终端矩阵 | `scripts/e2e-v2-tmux.sh` 当前断言 TUI 未申请 mouse tracking | 与 spec §7 推荐的全局捕获策略冲突，需同步策略、测试与 `Shift` 说明 |

现状中有一个必须优先修掉的确定性缺陷：

```text
run_loop:
  route = resolve(app)                 // 旧帧/批次开始时
  draw(...)
  recv + try_recv 批量处理
    -> 键盘可改变 route
    -> 后续 Mouse 仍收到旧的 route
```

这不是终端差异或偶发问题，而是 P0-C 的硬回归锁。

## 2. 目标架构

```text
App state
  -> ScreenRoute
  -> draw(frame, ..., &mut HitMapBuilder)
  -> FrameHitMap { frame_id, route, terminal_size, regions }
  -> terminal.draw(...) flush 成功
  -> last_presented_frame = FrameHitMap
  -> pointer event
  -> PointerState::on_event(last_presented_frame, event)
  -> PointerAction / PointerTarget
  -> 复用既有语义入口 dispatch
```

### 2.1 新模块与职责

建议新增：

```text
src/ui/v2/hit.rs
  FrameId / PointerTarget / HitRegion / FrameHitMap / HitMapBuilder
  Rect contains / intersect / translate / clip / anchor 检查

src/ui/v2/button.rs
  ButtonState / ButtonVisual / 统一 style
  Unicode 宽度按钮布局与窄屏降级

src/ui/v2/scrollbar.rs
  ScrollbarMetrics / track click / thumb drag 几何

src/terminal/agent/pointer.rs
  PointerState / PointerEvent / PointerAction / capture session
  事件状态机与路由清理规则
```

保留 `ModalHit` / `WorkspaceHit` 作为语义目标，但由 `PointerTarget` 包装；
不为了重命名而制造大面积无意义 diff。

### 2.2 HitRegion 最低字段

```rust
pub struct HitRegion {
    pub rect: Rect,          // 屏幕坐标，半开区间
    pub clip: Rect,          // 自身可见裁剪区
    pub local_rect: Rect,    // 诊断用局部坐标
    pub target: PointerTarget,
    pub button: MouseButton,
    pub enabled: bool,
    pub z: u16,
    pub anchor: VisualAnchor,
}
```

`FrameHitMap` 另带 `frame_id`、`route`、`terminal_size`、`scroll_offset`。
诊断字段不齐全时，strict probe 直接失败。

### 2.3 z 层级

采用 spec 建议值，并补 Agent 内部子层：

```text
Modal root          300
Modal content       310
Modal button        320
Workspace footer    200
Workspace row       100
Agent overlay        50
Agent scrollbar      30
Agent message row    10
Agent body            0
```

规则：

- 命中取最高 z；
- 同 z 重叠是规范错误，strict probe 必须报错；
- 区域先与 `clip` 和 frame area 相交，空交集不登记；
- Modal root 作为整屏阻断层，点击非按钮区域返回 no-op，不能穿透。

> 详细证据见 [`../handoff/2026-09-26-指针按钮与命中测试-handoff.md`](../handoff/2026-09-26-指针按钮与命中测试-handoff.md)。

**目标**：消除三套按钮状态与样式，明确鼠标捕获唯一所有者。

**改动**

1. 新增统一模型：

```rust
pub enum ButtonState {
    Idle,
    Hovered,
    Pressed,
    Disabled,
}

pub struct ButtonVisual {
    pub state: ButtonState,
    pub focused: bool,
}
```

2. 视觉优先级固定为：

```text
Disabled > Pressed > Hovered > Focused > Idle
```

3. Modal / Workspace / Agent 共用 `button.rs`：
   - hover 整块生效；
   - 无颜色终端 `REVERSED`；
   - pressed 额外 `BOLD`；
   - 颜色只来自 theme token；
   - 键盘 focus 与鼠标 hover 分开表达。
4. 按钮布局：
   - Unicode 显示宽度计算；
   - 不占终端最后一列；
   - 明确降级顺序：丢 hint → 缩短 label → 减少按钮 → 不绘制；
   - 不可见按钮不得登记 HitRegion。
5. 捕获生命周期：
   - `TerminalHost` 成为唯一 owner；
   - enter/leave 幂等且成对；

### P2：滚动条与拖动

> 进度（2026-09-26）：**实现完成**。新增 `src/ui/v2/scrollbar.rs` 的
> `ScrollbarMetrics`；track/thumb 登记到 HitMap（thumb 用更高 z + glyph anchor）；
> track click、thumb capture/drag、resize 取消 capture 已接入统一
> `PointerState`；已通过 anchor 下的 strict probe 与 PTY 矩阵。

**目标**：滚动条从“只画”变成与滚轮/键盘共用同一 scroll state 的完整交互。

**改动**

1. 新增 `ScrollbarMetrics`：

```rust
pub struct ScrollbarMetrics {
    pub track: Rect,
    pub thumb: Rect,
    pub max_top: usize,
    pub thumb_top: usize,
    pub thumb_height: usize,
}
```

2. 统一 offset 语义：
   - `offset == 0`：follow，thumb 贴底；
   - `offset == max_offset`：thumb 贴顶；
   - 无内容可滚：不登记滚动条 HitRegion。
3. 交互：
   - 点击 track：thumb 中心移动到点击位置；
   - thumb Down：保存 `grab_offset`；
   - Drag：绝对坐标映射，跨出 track 仍有效；
   - Up/Leave/RouteChanged/Resized：结束 capture；
   - resize 后重建 metrics，旧拖动会话作废；
   - 滚轮、PageUp/PageDown、拖动最终都写同一个 scroll state。
4. 滚动条纳入 HitMap 与 strict probe。

**验收**

- thumb 高度、贴顶/贴底、track click、grab offset、跨轨道拖动；
- resize 取消 capture；
- 无内容可滚时无 HitRegion；
- 滚动后旧可见行不可命中新内容；
- 键盘与鼠标滚动结果一致。

## 6. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 绘制接线漏登记 | 画面可见但不可点 | strict probe anchor/中心/四角检查；每个 route 做矩阵 |
| 登记了不可见区域 | 幽灵点击 | clip/可见帧检查；空交集不登记；外扩一格反例 |
| 批量事件仍用旧帧 | 错点/穿透 | 帧失效后停止本批 Mouse；专门 stale 锁 |
| z 层级冲突 | 按钮被 overlay 吃掉或穿透 | 显式 z；同 z 重叠 strict 失败 |
| 捕获未成对 | 退出后终端仍吞鼠标 | TerminalHost 单一 owner + PTY 原始字节断言 |
| 旧 hit-test 与 HitMap 并存 | 再次形成双几何 | 切片内删除旧生产入口；静态/测试防回退 |
| P3 与旧产品裁决冲突 | 实现方向返工 | 9/25 后文档为准；D1/D2 已裁决 |
| 测试公式再次复制布局 | 探针失效 | pin 必须同时跑 strict probe；优先共享 helper |
| `Cargo.lock` 与 pinned ratatui 解析不一致 | 裸跑 test 污染工作树，`--locked` 失败 | 单独裁决并提交锁文件刷新，或明确非 `--locked` 门禁口径 |
