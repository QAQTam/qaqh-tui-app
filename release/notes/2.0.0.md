# qaqh-tui 2.0.0

独立 TUI 正式版，仅包含终端客户端，**不包含、安装或更新 qaqh-daemon**。
请自行准备兼容的 Ringing v2 daemon；已有 daemon 可使用 `--no-spawn` 连接。

## 本版重点

- 修复空闲 Tick / 无变化鼠标移动触发的不必要绘制。
- 普通用量、团队、压缩进度与设置更新采用差分绘制，避免清屏闪烁。
- 历史块共享渲染行，仅复制可见窗口；缓存命中时不再全量复制正文和工具输出。
- 修复快照重载、回合重开、时间回填与等长摘要更新的缓存失效。
- 会话列表刷新去重、失败退避及超时保护。
- F10 或 `/settings` → **TUI 本地 → 渲染：动效模式 / 性能模式**。
  性能模式采用低频明暗圆点，关闭扫光与滚动缓动；设置仅保存在本机，不回传 daemon。
- 移除左侧会话栏的“本端已打开”方块，保留活动状态标记与选中底色。

## 下载

| 文件 | 平台 |
|---|---|
| `qaqh-tui-2.0.0-windows-x64.zip` | Windows x64（MSVC） |
| `qaqh-tui-2.0.0-linux-x64.tar.gz` | Linux x64（GNU，Ubuntu 22.04 / glibc 2.35 或更新） |
| `qaqh-tui-2.0.0-macos-intel.tar.gz` | macOS Intel x64（目标最低 macOS 13） |
| `qaqh-tui-2.0.0-macos-arm64.tar.gz` | macOS Apple Silicon ARM64（目标最低 macOS 13） |

下载后解压，运行其中的 `qaqh-tui`（Windows 为 `qaqh-tui.exe`）。
`SHA256SUMS.txt` 提供四包校验值；每包含许可证和固定构建依赖信息。
本版未配置 Windows 代码签名或 macOS 签名/公证，系统可能要求确认来源。

## 边界

性能模式目前简化动画，**并未启用纯文本/按行渲染**。长 Markdown 与代码块仍可能
整块重解析；尚未给出跨平台 CPU/RSS 性能承诺。daemon 不在本次发行范围内。
